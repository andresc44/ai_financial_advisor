# Project Coding Conventions & Architecture

## Tech Stack Constraints
- Python 3.14+, typed with type hints wherever applicable.
- Use explicit error handling—avoid bare `except:` statements.

## Architectural Rules
- all new files of code generated should fall under /src at some level
- Do not modify existing function signatures without adding fallback parameters.

## Code Style & Formatting
- Follow PEP 8 guidelines.
- Write docstrings for all public classes and methods.
